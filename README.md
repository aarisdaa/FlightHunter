# FlightHunter

A full-stack flight price tracker. Add a route and a date, and FlightHunter records the price over time, shows the trend, and tells you when it drops below your target.

## Features

- Track any route (3-letter airport codes) for a given departure date, with an optional target price
- Price history for every route, with latest, lowest and change since the first check
- Highlight when the price reaches your target
- Manual "Check price" button plus automatic background refresh (every hour by default)
- Pluggable price provider: a built-in mock provider works with no API key, and a real provider can be added in one file
- Interactive API docs at `/docs` (FastAPI)

## Tech stack

- **Frontend:** React 19, Vite, plain CSS, SVG sparkline (no chart library)
- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic
- **Database:** PostgreSQL 16 (Docker Compose)

## Run locally

1. **Database**
   ```bash
   docker compose up -d
   ```
2. **Backend**
   ```bash
   cd backend
   python3 -m venv venv && source venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   uvicorn app.main:app --reload
   ```
   API: http://localhost:8000 · docs: http://localhost:8000/docs
3. **Frontend**
   ```bash
   cd frontend
   cp .env.example .env
   npm install
   npm run dev
   ```
   App: http://localhost:5173

## API

| Method | Path | Description |
|---|---|---|
| POST | `/watches/` | Start tracking a route (takes the first price right away) |
| GET | `/watches/` | List routes with price summary and history |
| GET | `/watches/{id}` | One route |
| GET | `/watches/{id}/history` | Price history |
| POST | `/watches/{id}/refresh` | Check the price now |
| DELETE | `/watches/{id}` | Stop tracking |
| GET/POST/PUT/DELETE | `/flights/` | Simple flight records (original CRUD) |
| GET | `/health` | API and database status |

## Configuration (`backend/.env`)

| Variable | Default | Meaning |
|---|---|---|
| `DATABASE_URL` | none | PostgreSQL connection string |
| `PRICE_PROVIDER` | `mock` | Price source (`mock` is built in) |
| `REFRESH_MINUTES` | `60` | Automatic refresh interval, `0` to disable |
| `CORS_ORIGINS` | `http://localhost:5173` | Allowed frontend origins, comma separated |

## Using real prices

By default FlightHunter shows **simulated prices** (`PRICE_PROVIDER=mock`), and the UI displays a "Demo data" notice while the mock provider is active.

Prices are generated by `backend/app/services/provider.py`. To use a real flight-price API, add a class with a `quote(origin, destination, departure_date)` method that returns `(airline, price)` and select it in `get_provider()`. You will need your own API key from the provider.
